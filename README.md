# Bilingual Clinical RAG Assistant

A bilingual (English/Arabic) agentic RAG system that answers clinical questions grounded only in a source corpus of medical notes, with citations back to the exact chunk used. It combines hybrid (lexical + dense) retrieval, cross-encoder reranking, a LangGraph agent, and automated RAGAS evaluation.

## Why this project

Two of the fastest-growing, highest-stakes applications of applied AI today are healthcare and Arabic-language NLP - both explicit priorities under Saudi Vision 2030's push to digitise healthcare delivery and build sovereign Arabic-language AI capability. Most RAG tooling is built and evaluated English-first; this project demonstrates the harder version of the problem: a single retrieval and generation pipeline that performs reliably in both English and Arabic over the same clinical corpus, with the grounding and citation discipline that healthcare applications require (no answer is generated without traceable source evidence, and the system is instructed to say so when it doesn't know).

## Architecture

```
data/raw (en/ar .txt)
   -> ingestion:    chunking with overlap + language/source metadata (src/ingestion)
   -> retrieval:    BM25 (lexical) + FAISS over multilingual embeddings (dense),
                     fused via Reciprocal Rank Fusion              (src/retrieval)
   -> reranking:    cross-encoder rescoring of the fused shortlist (src/retrieval/reranker.py)
   -> agent:        LangGraph pipeline -
                     detect_language -> retrieve -> generate -> format_response
                                                                  (src/agent)
   -> generation:   Groq-hosted LLM, answers strictly from retrieved context,
                     in the query's own language, with citations
   -> evaluation:   RAGAS (faithfulness, answer relevancy, context precision/recall)
                     over a 14-question bilingual test set             (src/eval)
   -> UI:           Streamlit chat interface                             (app/main.py)
```

## Tech stack

- **Retrieval**: FAISS, `rank-bm25`, `sentence-transformers` (multilingual embeddings + cross-encoder reranker)
- **Agent orchestration**: LangGraph, LangChain
- **LLM**: Groq (OpenAI-compatible hosted inference)
- **Evaluation**: RAGAS
- **UI**: Streamlit
- **Language**: Python 3.11+

## Setup

```bash
pip install -e ".[dev]"
cp .env.example .env        # add your GROQ_API_KEY
python -c "from src.ingestion.chunking import ingest; ingest('data/raw', 'data/processed/chunks.json')"
streamlit run app/main.py    # or: python scripts/ask.py "your question"
```

Run tests with `pytest`. Run the evaluation with `python -m src.eval.run_eval`.

All notes under `data/raw/` are **synthetic**, written for this project and styled after the public MTSamples medical-transcription format. No real patient data is used anywhere in this repository. See `data/README.md` for details.
